USB Hardware Key Manager

Daftarkan flashdisk fisik sebagai kunci otorisasi lokal untuk USB Launcher aplikasi WARISCRYPT.

Daftarkan Perangkat Flashdisk Baru

Sistem akan membuat kunci kriptografis unik 256-bit dan menyimpannya dalam berkas wariscrypt.key yang dapat Anda unduh dan letakkan di root flashdisk Anda.

Panduan Menjalankan USB Launcher Pendamping

  1. Unduh berkas wariscrypt.key di atas.
  2. Salin berkas tersebut langsung ke dalam flashdisk Anda (misal drive E:\wariscrypt.key).
  3. Jalankan pendamping launcher di terminal / folder proyek: 
    python usb_launcher/usb_launcher.py
  4. Ketika flashdisk terdeteksi, launcher akan memverifikasi fingerprint ke API backend dan otomatis membuka browser web Anda ke portal WARISCRYPT!
